## Getting Started

To explore the projects locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/ayshanassar1/nuvento-training-tasks.git
   ```

2. Open the downloaded folder in Visual Studio Code.
3. Navigate to the project you want to explore.
4. Read the individual project's README file for setup instructions.
5. Install the required dependencies and run the project according to its instructions.

Each application may have its own dependencies, configuration, and execution steps.
