# Website Intern

A simple and responsive React website created to display intern information and their respective departments.

## Live Demo

**[View the Live Website](https://ayshanassar1.github.io/Website-intern/)**

## Features

- Displays intern information in a structured layout.
- Organizes details by department and role.
- Includes an interactive greeting button.
- Uses reusable React components for a clean structure.
- Provides a simple and user-friendly interface.

## Technologies Used

- **React** – Building the user interface.
- **JavaScript** – Implementing functionality and interactions.
- **CSS** – Styling and layout.
- **Vite** – Development server and production build tool.
- **Git & GitHub** – Version control and source code hosting.
- **GitHub Pages** – Hosting the live website.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js and npm installed.
- Git installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ayshanassar1/Website-intern.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Website-intern
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Production Build

To create a production-ready build, run:

```bash
npm run build
```

The generated files will be available in the `dist` folder.
